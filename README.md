# React Starter

A minimal React app built with Vite and JavaScript.

## Development

Requires Node.js 22.16 or newer.

```sh
npm install
npm run dev
```

Open the local URL printed in your terminal. Edit `src/App.jsx` to change the page
and `src/index.css` to change its styles.

## Production build

```sh
npm run build
npm run preview
```

The production output is saved in `dist/`.
